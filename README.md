# NeferDiabetes
Using historical glucose data, meal intake, activity, and insulin sensitivity, AI models suggest precise basal-bolus dosing or insulin adjustments. Suggest life style and follow up tests and doctor visits ( requiered tests and scans )



# DEMO LINK : https://drive.google.com/file/d/1XehTmpWe5-7XdDNA4OFAC1ZP-IMLpSzK/view?usp=sharing




# Features

DR Classification: Uses a custom PyTorch model with EfficientNet-B3

Class Balancing: Handles uneven data with oversampling and focal loss

Image Processing: Applies data augmentation for better training

User Interface: Gradio interface for easy image predictions

Confidence Scores: Shows prediction scores with bar charts

Model Saving: Saves the best model as dr_model.pth
